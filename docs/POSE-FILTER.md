# Pose外れ値ゲート

時刻整列後のPoseをNode別のPoseMotionFilterで検査し、採用した測定だけを描画用履歴へ保存する。Node間で判定基準を共有しない。外れ値除去の後に下記の補間・短時間予測を適用する。共分散付き融合は未実装。

## 判定

- 位置は3要素、クォータニオンは4要素で有限値に限る。位置の絶対値は100km以下、クォータニオン長は1からの誤差0.05以下を要求し、その範囲で正規化する。
- tracking lost、以前に採用した測定以下の時刻・sequenceは拒否する。
- 前回採用した位置・姿勢から、移動20m/s・回転20rad/sの上限を検査する。数値揺れ用に距離5mm・角度0.005radを加算する。qと−qは同じ回転として扱う。
- 0.5秒を超える欠測後は、互いに整合する3測定を確認して復帰する。欠測全体の時間についても前回採用位置からの速度上限を守る。候補間の不整合や追加の欠測で確認をやり直す。
- 不正測定、古い測定、追跡中断、同期不良では復帰候補を破棄する。拒否したPoseは、次の判定基準やPoseHealthの鮮度更新に使わない。拒否が続けば既存の鮮度ゲートにより追跡喪失・出力保護へ移る。

初回測定には比較対象がないため、形式・品質を検証して基準とする。参照空間revisionの変更は校正失効処理で別途扱い、明示的な追跡基準の再設定・再接続時にフィルターをリセットする。失効した校正をこのフィルターで復活させない。

## 診断

Inspectorは選択Nodeの拒否数を表示し、警告アイコンのhelpとアクセシビリティラベルで直近の理由を英語・日本語・简体中文で示す。次の正常採用で直近理由を解除する。診断JSONはNodeごとにposeRejectedCountとposeRejectionを保存する。件数は現在の追跡セッション内の値で、明示的な基準リセットや再接続でリセットする。

## 映像取得時刻への補間・予測

採用測定をHost時計の時刻、位置、クォータニオン、品質として最大128件保持する。描画スレッドは、実際に投入する映像フレームの`telemetry.captured`へPoseを合わせる。画面表示時刻へカメラだけを先行させる処理ではない。

実測時刻に一致すれば実測を使用し、2測定の間なら位置を線形補間、回転をslerpで補間する。100msを超える測定間隔やHost時刻の逆転では履歴を切り、異なる連続区間を補間しない。

映像時刻が最新Poseより新しい場合のみ、直前2測定から定速度で予測する。双方の測定が正常品質であること、測定間隔1〜100ms、予測幅30ms以下、推定速度20m/s・角速度20rad/s以下、追加移動20cm・追加回転0.2rad以下を要求する。上限超過をクランプして有効Poseと見なすことはせず、対応不能とする。

映像と履歴はソースIDで照合する。映像取得時刻が未知、履歴より古い、履歴不足、品質プロファイルの期限超過、予測上限超過の場合、本番の追跡映像は`poseUnaligned`として保護する。静止カメラにはこの整列を要求しない。プレビューでは従来の相対Poseをフォールバックとして使用できるが、本番では使用しない。

補間後にステージ変換を適用する。再接続・参照変更・追跡喪失・同期不良・基準リセットでは履歴を破棄する。正しい時刻のPoseが得られても、失効した校正や追跡喪失の保護は解除しない。

## 予測誤差

次の正常な実測が届く際、その時刻を直前の履歴から予測できる場合に位置差・最短回転角差・予測時間幅を保存する。これは次のセンサー測定との残差であり、物理的な正解値との誤差ではない。予測できない間隔や品質では未測定とする。

Inspectorは現在の実測／補間／予測／対応不能、予測時間幅、次の測定との位置差・回転差を3言語表示する。診断JSON v10の`metrics.poseAlignment`に、描画側の状態と誤差・誤差の計測時間幅を記録する。値を全Nodeへ一括して適用せず、描画対象の履歴を使う。

## 検証範囲

全99件のテストで、位置・回転の飛び、NaN、非単位クォータニオン、古い時刻・sequence、欠測復帰、復帰中断、Node分離、参照変更、拒否後の鮮度低下に加え、補間・予測・残差・各上限・履歴の容量と分断を検証する。Metal上でもソース照合、補間・予測時の正常出力、取得時刻不明・ソース不一致・予測上限超過時の保護を確認した。

実iPhoneや外部トラッカーでのノイズ分布、高速パン・移動、遮蔽復帰時の誤拒否率、急な停止・加速時の予測誤差、実際の合成位置ずれと復帰動作はPending。既定値は暫定の保守的な値で、機種別の性能認定ではない。
