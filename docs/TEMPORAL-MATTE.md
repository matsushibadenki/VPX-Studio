# マットの時間安定化

クロマキー境界のフレーム間ちらつきを抑える任意のGPUフィルター。Inspectorでクロマキーを有効にしてから「マットの時間安定化」を有効にする。既定は無効、履歴強度の初期値は0.5、範囲は0〜0.8。本番中の有効化・強度変更はUIで抑止する。

## 画素単位の判定

レンズ補正とSDR線形化後の映像・マットを前フレームと比較する。現在のアルファが0.05〜0.95の不確定な境界だけを処理する。色差はRGB各成分の最大絶対差、アルファ差は前回の安定化済みアルファとの差を使う。

色差0.04〜0.08、アルファ差0.1〜0.25のsmoothstepで履歴の信頼度を下げる。設定強度に信頼度を掛け、現在値と前回値を混合する。確定した前景・背景、大きな色変化、アルファの大きな変化は現在値を使う。これは動き補償・光学フロー・深度による判断ではない。

## フレーム単位の履歴管理

- 最大100ms以内で取得時刻・frame IDが増加する同一ソースだけを連続履歴として使う。
- 同じ取得時刻・frame IDの再描画では前回のマットをそのまま使い、表示fpsによってフィルターが重ならないようにする。
- ソース、出力サイズ、入力寸法・形式、色変換、レンズ補正、キーしきい値・柔らかさ・履歴強度の変更で初期化する。
- 取得時刻不明、不正値、入力断、同期・追跡・GPU等の出力保護、機能無効化で履歴を破棄する。正常復帰の最初のフレームは現在値から開始する。

GPUに線形映像RGBA16FloatとマットR16Floatを各1枚保持する。CPU／SwiftUIへフレームを戻さない。Frame Graphは合成後のmatteHistoryパスで履歴をコピーし、同一Metalキューの順序とフェンスで同期する。再描画時はコピーし直さない。

追加履歴メモリは約10バイト／出力画素（4Kで約83MB、アロケーションの付加分を除く）。機能無効・強度ゼロでは履歴テクスチャを解放する。複数Nodeのピクセル履歴を一括保持せず、描画している入力の1組のみを持つ。

## 診断と検証

3言語で有効化・強度、履歴なし／初期化／フィルター適用／同一フレーム再表示を表示する。診断JSON v11はrenderConfigurationのtemporalMatteEnabled／temporalMatteStrengthと、metrics.temporalMatteModeを保存する。「フィルター適用」はフレームが履歴利用可能という意味であり、全画素を混合したという意味ではない。

全105件のテストで、連続性・ソース・パラメータ・サイズ・時刻・有効化復帰を確認。実GPUのマット画素値を比較し、小さな境界変化の減衰、同一フレーム再描画の不変性、確定前景／背景、大きな色変化、ソース切替・無効化復帰で古いマットを引きずらないことを確認した。

実カメラの髪・半透明・急な動き・照明変動でのちらつき／残像評価と、機種別4K60のGPU時間・メモリ測定はPending。深度・人物セグメンテーション・動き補償の統合はNextとして残す。
