# 深度・confidenceのデバッグ表示

Inspectorの表示パスで「深度（未補正）」または「深度信頼度（未補正）」を選ぶ。選択中のNodeの生データを表示する診断機能であり、実写との幾何位置合わせや深度合成は行わない。縦横比を維持して余白を黒く表示する。

## 表示

深度はFloat32 little endianのメートル値を使用し、近い距離を暖色、遠い距離を寒色にする。距離上限は初期値10m、操作範囲0.5〜20m。上限より遠い値は上限色で飽和する。NaN、無限大、0以下の距離、confidence=0の画素は黒くする。confidence=1の深度は半分の明るさ、confidence=2は通常の明るさで示す。

信頼度ビューは受信値0／1／2を赤／黄／緑で表示する。距離の有効性や精度そのものを表す画像ではないため、距離が無効でも受信したconfidence値は確認できる。

両ビューは未補正のセンサー画像。実写へのUV対応、レンズ歪み補正、カメラPoseによる再投影、人物セグメンテーションとの統合は未実装。RGB映像のデコード・色変換に問題があっても、プレビューで深度診断だけを確認できる。本番では描画経路が表示パスを合成へ強制し、深度診断で本番保護を迂回しない。

## 配送と鮮度

Mac受信時の時計モデルで変換したHost取得時刻を使用する。モデルは同期が有効なNodeの最新パケットを描画設定へ渡す。GPU投入時にもソースIDと取得時刻を確認し、500msを超える古い深度、50msを超える未来時刻、不正な時刻、別ソースの深度は表示しない。データが利用できない場合は無地の暗色を表示し、古い距離画像を残さない。

新規のNode／frame ID／取得時刻／寸法に対してのみR32Float深度とR8Uint信頼度のテクスチャを作成する。同じパケットの再描画では転送しない。新規パケットは別の不変テクスチャ対へ転送し、実行中のGPUコマンドが参照している内容をCPUで書き換えない。キャッシュは最新1組を持ち、過去の組は参照中のコマンド完了後に解放される。

通常の合成や別の表示パスではキャッシュを解放する。転送・保管量は深度画素数あたり約5バイトであり、表示出力の4K画素数へCPU展開しない。CPU上のwireデータからGPUへのコピーは新規パケットごとに発生し、ゼロコピー経路ではない。

## 診断と確認

英語・日本語・简体中文でパス、距離上限、データなしの状態、説明のhelp、深度取得後の経過時間を表示する。時刻は同期モデルに基づく推定であり、小さい負の経過値は許容する未来側誤差の範囲を示す。診断JSON v12のmetrics.depthPreviewに利用可否・寸法・経過時間、renderConfigurationに表示距離上限を記録する。

全112件のテストを通過。ソース・鮮度・不正時刻、新規転送と再利用、不変テクスチャを検証し、実GPUの画素値から深度色・confidence色・縦横比・無効距離・期限切れ・別ソースの非表示と本番保護を確認した。

回帰テストで固定入力再生の10秒待ちがタイムアウトしたため、有限再生の完了・映像／Pose配送数は3フレームの短いフィクスチャで検証するよう変更した。標準の120フレーム・640×360／60p定義は変更していない。画像生成は横方向の2つの行テンプレートを使い、内側ループの除算・剰余を減らした。標準パターンのフレーム・色・チェッカー境界を比較し、画像が変わらないことを確認する。完了テストを実機の60fps性能認定とは扱わない。

実LiDAR搭載iPhoneでの距離精度・画像方向・confidenceの挙動・再接続と、機種別の処理負荷はPending。合成での遮蔽判定やマット融合の完成とは扱わない。
